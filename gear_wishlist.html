Sampler

Desktop

1010music Blackbox 2

Owned Studio + Live

Compact sampling workstation — 4 tracks, each a different instrument type: Slicer (up to 128 slices, auto-scan or manual), One-Shot (16 pads with per-pad pitch/filter/envelope/reverse), Loop, Multisample, Shredder (granular), or External MIDI. 4" touchscreen, 4 knobs, battery-powered (4 hrs).

Studio Load WAVs via USB-C (microSD Mode — card appears as removable disk on Mac, drag and drop). Streams samples up to 4GB from microSD. Slicer auto-detects transients; One-Shot mode gives per-pad control of pitch, level, filter, decay, reverse.

Live Digitone 2 sequences slices via TRS MIDI (C2 = slice 1, chromatic upward). Battery-powered, no laptop. Per-track overdrive, master delay (beat-synced), reverb (with freeze), DJ FX (bitcrusher, flanger, filter, gater, repeater), 4-band parametric EQ, compressor.

MIDI: TRS MIDI In (auto-detects Type A/B) + TRS MIDI Out + USB-C MIDI. Per-track MIDI channel. Assign a free MIDI channel in CHANNEL_MAP. Also does TRS clock sync. Needs TRS-to-DIN Type A adapter cables for the dawless MIDI chain.

MIDI Router / Hub

1U

iConnectivity mioXL

Primary Pick Studio + Live

USB MIDI host + interface + router in 1U. 10 USB-A host ports (4 front, 6 rear) — every synth in the rig plugs in via USB. Separate USB-B port for the computer. 8 DIN MIDI in + 12 DIN MIDI out. Own power supply (12V/36W). Ethernet for RTP-MIDI.

Studio Replaces the 8-port USB multiport. All synths connect to the mioXL via USB; Reason sees everything through one USB-B cable. 10 host ports = room for the whole rig + future gear.

Live Disconnect the computer — the mioXL becomes a standalone USB MIDI host. Digitone 2 sends MIDI through the mioXL to all synths over USB. No daisy chain, no thru boxes, no splitters. Save a “dawless” routing preset; recall it from the front panel.

Routing configured via Auracle software (Mac). Once saved to device (32 presets), runs fully standalone. Front-panel preset recall + MIDI activity monitor.

Solves two problems at once: (1) not enough USB ports for the computer, (2) no way to route MIDI from Digitone 2 to all synths without a computer. Manual verified: manuals/mioXL_User_Manual.pdf

The setup

Two modes, one rig. Everything acquired here serves both the studio and a fully laptop-free live/jamming setup. Gear must work in both worlds.

Studio Compose in Reason → Reason sequences all hardware via USB MIDI → process stems through rack gear → mix down premasters at -6dB
Live Transfer MIDI to Digitone 2 (via MidiDigi bridge app) → Digitone 2 sequences all hardware → rack gear processes audio → ZED-10 → PA. No laptop on stage.

The Digitone 2 is the brain for live. It stores entire songs as patterns (transferred from Reason using the MidiDigi bridge). Any MIDI-controllable gear in the rack gets a channel on the Digitone and becomes part of the dawless live set. Rack gear that only processes audio (compressor, effects) works in both modes without MIDI.

Requirement for sound sources: all synths, drum machines, and samplers in the rack must respond to MIDI note/CC messages so the Digitone 2 can sequence them live. USB or 5-pin DIN MIDI. No computer needed to make sound.
